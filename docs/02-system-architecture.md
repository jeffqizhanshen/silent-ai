# 02 系统总体架构

状态：候选设计，待验证。以下边界用于实验，不构成最终选型。

```text
 [面颊/下颌] → [IR/ToF ×N] ┐
 [镜架运动]  → [IMU]         ├→ [采集 MCU + 单调时钟 + 缓冲]
 [肌肉活动]  → [可选 sEMG]  ┘        │ USB/无线（人体安全约束优先）
                                      ↓
      [授权参考视频 + 同步事件] → [本地采集/同步/质量监控]
                                      ↓
                         [预处理 → 识别/拒识 → 可编辑文本]
                                      ↓ 用户确认并授权
                         [LLM API → TTS → 系统蓝牙耳机]
```

## 职责与边界

- 眼镜实验夹具提供可调整传感器方位，单片机以统一单调时钟标记数据；台架可用 USB，人体带电极试验按 E01 安全规则隔离。BLE 是候选，先以可靠采集为主，不假定带宽、丢包率或功耗已达标。
- 主机保存原始数据和配置，独立校准时钟、对齐、质量检查与版本管理；识别在本地候选执行。视频仅用作参考，视频不可作为未佩戴摄像头的产品模型输入，也不能泄漏到待测传感器模型。
- 智能手机/PC 为识别和对话平台；文本交互有编辑、拒识和明确发送；LLM 请求只包括用户授权的必要内容，网络、供应商与留存策略需明确。输出通过操作系统音频路由至独立蓝牙耳机，眼镜无需承担音频链路。

## 接口草案

每样本含设备 ID、模态/通道、序列号、设备单调时间、原始值、状态/质量、配置版本；批次另含开始时钟、标定和单位。主机保留接收时间，不以其代替采样时间；检测丢包、时钟重置、溢出，原始数据不可覆盖。具体 BLE MTU、编码、加密和传输速率为待验证设计；连接、重连、乱序和隐私威胁在实现前评审。

## 降级与安全

低置信/无效输入不自动发送；缓存满/断连显式标记数据缺口，恢复不伪造；用户可停录、停播、撤回数据。默认不上传任何视频和生物信号；本地访问控制与加密备份在数据采集前落实。
