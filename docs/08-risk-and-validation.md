# 08 风险与验证

| 风险 | 后果 | 实验与应对 |
|---|---|---|
| 口型同形、声调/舌位不可见 | 先天歧义，语言模型可能自信地猜错 | 音节最小对照、四声/同形混淆矩阵；拒识与确认，不以语言模型伪造感知能力 |
| IR/ToF 近距、角度、皮肤反射及串扰 | 信号饱和或不稳定；VL53L1X 小于 4 cm 不准确 | 实测几何、台架距离/角度/光照扫描、顺序触发对照；必要时换候选 |
| 镜架滑动和头动 | 面部特征被污染 | 静止/点头/转头与重新佩戴配对；测 IMU 补偿和非补偿收益 |
| 个体、时间差异 | 训练数据不能推广 | 锁定未见受试者、跨日会话、未见文本；按人汇报和参与者级区间 |
| sEMG 电极、肌电串扰/电气安全 | 不适、伪迹或危险 | 仅安全审核后电池无线采集；评估增益与佩戴负担，必要时取消 |
| 视频和生物数据泄露 | 敏感信息暴露 | 同意与撤回、权限隔离、本地加密，明确数据流，未经授权不上云 |
| 漂移/同步错误及数据泄漏 | 虚假性能 | 起止同步、测残差、分组隔离及锁定测试，归一化仅训练集拟合 |
| 功耗、带宽、延迟 | 原型无法持续使用 | 实测系统状态、电压、采样及无线参数；先有耗电预算再评估续航 |
| 小样本及过度调参 | 结果不稳、无法推广 | 报人数、试次数、置信区间、预注册和负结果；独立重复验证 |

## 指标口径（每次报告条件、分母与统计）

- **CER** = (字级替换 + 删除 + 插入) / 参考字数。预先冻结简繁、数字、标点、空格和大小写规范，报告逐人及整体；零参考字的空闲试次不计算 CER，单列误触发。拒识试次的 CER 不能只计算被接受子集而掩盖错误：同时给全试次（拒识按空输出计删除）与接受子集 CER、覆盖率。
- **识别延迟**：主指标从参考发音动作结束的时间（视频人工边界及误差注明）至最终稳定文本显示；报告 p50/p95 和分布，区分首字延迟、采集缓冲、传输、解码、端点等待。总对话延迟另外含用户确认、网络、LLM、TTS 和耳机；不可混用。
- **拒识率**：符合预定义质量且有意输入的试次中被拒绝数/总数；阈值在验证集冻结，另报空闲/非目标的误接受率、接受覆盖率及其 CER，明确端点超时与拒识规则。
- **功耗**：以测量电压下的平均电流和平均功率（含采集、MCU、无线及板级损耗）分别报告静止、连续采集、传输等状态与时长；同时记录峰值、仪表带宽、供电、配置；手机/PC 和耳机能耗单列。待测不是零。
- E01 同步误差、缺失率、饱和率、可重复性和消融指标详见实验方案。报告独立受试者数、每人样本、排除和参与者级置信区间；小样本区间不稳定必须明确。
