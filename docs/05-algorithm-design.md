# 05 算法与中文识别方案

状态：研究候选，尚无模型或效果。连续自然语言是长期目标；E01 先看传感器的信息量和扰动鲁棒性。

## 处理链

保留带设备时钟与质量标记的原始采样 → 时钟映射与对齐 → 用训练集拟合的标定/滤波/标准化 → 按时间切片或流式缓存 → 质量/活动检测 → 序列编码 → 中文解码 → 置信度、拒识与用户确认。严格区分离线双向 BiLSTM 与在线模型；在线模型只能使用有限右上下文，报告算法缓冲延迟。

## 实验阶梯

1. E01：空闲、面部动作、少量音节/短词的重复性和组间可分性；先用简单特征与线性分类/DTW 等基线，固定相同数据、窗口、训练预算。IMU 作为独立输入、补偿输入与无补偿三种条件分别对照。
2. E02：按用户、会话和句子拆分，比较 CNN+BiLSTM、CNN+Transformer、CTC 的离线短词/句基线。sEMG 有安全和采样前提；缺失模态要显式标记，不能补造。
3. 连续流式：采用因果或有限上下文编码、CTC 前缀 beam search 与端点检测；在独立测试上衡量端点、字词错误与端到端延迟。没有足够数据或可分性时不进入这一阶段。

中文可研究汉字直接建模，以及声母/韵母/带声调拼音序列加词典/语言模型的对照。视觉口型存在同形音、舌位与声调不可直接观察的问题；sEMG 可能增加信息但也不保证可辨，语言模型只能提供概率先验，不能把猜测当事实。对最小对照组、同音/近口型、四声分别分析，报告真实错误并允许拒识、编辑。语言模型训练数据和词表须隔离测试集，避免答案/提示泄漏。

## 公平对照及评估

IR、IMU、sEMG 单模态、IR+IMU、IR+sEMG、IMU+sEMG 和三模态仅使用同一完整配对子集；报告各模态可用率与数据量、额外硬件和功耗；如某模态不可用，明确不比较而非填零造结果。受试者内跨会话、未见受试者、未见文本分别评估；预先选择主要分析，参与者级 bootstrap 置信区间，禁止对重复片段当独立受试者。度量定义见风险文档。
