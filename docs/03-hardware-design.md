# 03 硬件架构（实验候选）

## 可拆卸试验平台

普通镜架 + 无尖锐边缘的可调夹具，在左右镜腿靠近颧部、脸颊及可观察下颌区域安装多点光学模块，记录每点与皮肤的静态距离、角度、遮挡、视场和固定方式；避免眼睛照射和压迫。镜架 IMU 固定在刚性位置；必要时增加独立参考 IMU，以识别整体头动和镜架滑移。单个 IMU 无法直接还原面部相对运动，补偿有效性须对照验证。脸颊下颌距镜架可能小于 ToF 最小工作距离，不能先假设可安装。

## 采集链

候选 nRF5340 DK 或现有通用采集板 + 多通道 IR/ToF + BMI270；sEMG 作为独立对照，仅在电气安全审核后追加。多光学模块可能固定 I²C 地址冲突，需逐个 XSHUT 重分配、I²C 多路复用或分总线，核对具体模块；多光源串扰通过顺序触发与同步/并行对照测量，记录每路实际频率及积分窗口。传感器结果保存状态位，不将 IR 强度当作毫米距离。

## 时序、带宽与功耗

以硬件时间戳记录采样或有效积分窗口，FIFO 溢出、时钟重置、序号丢失可检测；无线数据包打包减少开销但增加延迟。估算采用 `Σ(通道数×采样率×每样本字节)+协议开销`，实测吞吐和丢包；不要以 PHY 速率当有效吞吐。用电源分析仪在指定电压、频率、光源占空比、BLE 连接参数下测采集、传输、待机完整平均电流及峰值；外设、稳压、板级损耗单列。标称器件电流不等于续航。

## 人体与实验安全

未经完整装配光学安全评估，不将器件 Class 1 属性直接外推至任何光路；评估朝向、遮挡和反射。电极必须由有经验人员审查接触、清洁、受试者排除及电气隔离。人体接触电极期间仅电池供电、无线传输，断开 USB、充电器和所有市电连接，勿边充电边佩戴；电池供电本身不等于安全认证，须评审故障和漏电。出现疼痛、皮肤刺激、热感立刻停止。严禁自行将未审查的模拟电路直接接人。
