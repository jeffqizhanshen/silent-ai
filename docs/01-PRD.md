# 01 产品需求文档

状态：初始化草案，2026-11-10；未验证、非交付承诺。

## 问题与目标

开放式办公中，用户希望不发声地与 AI 连续交流，并通过独立蓝牙耳机获取私密回复。最终目标是自然无声中文句子输入；本阶段先回答传感器能否捕捉区分性特征，不承诺识别准确率、自然输入速度或跨用户能力。

## 用户与场景

研究参与者在室内安静或正常办公环境，佩戴可调实验眼镜，通过无声口型输入；手机/PC 负责识别、AI 与耳机输出。口型可能仍被旁人看见；耳机泄音与屏幕可见性需另行验证，不能宣称绝对私密。

## 需求与优先级

| 优先级 | 需求 | 验证方式/状态 |
|---|---|---|
| P0 | 无声为主要输入；连续中文为最终目标 | 分级实验，待验证 |
| P0 | 先采集多模态带时间戳信号，比较单模态和融合 | E01，未开始 |
| P0 | 独立测试、CER、延迟、拒识率、功耗及个体差异 | 指标见风险文档，未测 |
| P0 | 原始面部视频与生物信号默认本地，授权、撤回、删除 | 数据规范与实际流程审核，未实现 |
| P1 | 显示识别文本、允许修改/确认、低置信拒识，用户主动发送 | 原型验证，待设计 |
| P1 | 经用户同意调用 LLM；耳机系统音频输出和中止 | 端到端测试，待实现 |
| P2 | 连续流式识别、个性化校准、断连恢复 | 视实验结果确定 |

## 非目标与边界

本次不做量产、工业设计定型、医疗诊断、完整眼镜或保证任意中文/任意用户可用。不以正常发声作为主要输入，不将实验室摄像头作为默认产品传感器。LLM 不得默默替用户改写不确定识别并发送；确认及可取消交互需保留。

## 阶段验收

E01 输出有质量控制的多用户样本、配对模态对照、条件和不确定性、功耗/时间同步记录及继续/调整/停止建议。后续 E02/E03 与集成以实际门槛为准，见路线图；16 周为规划窗口，非效果保证。
